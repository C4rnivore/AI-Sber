# AI-Sber
«Цифровой хранитель: AI для сохранения и изучения малых языков России»

## Описание
Десятки языков коренных народов России находятся на грани исчезновения. Уходят носители, а вместе с ними - уникальные культурные коды, фольклор, знания. Существующие цифровые инструменты (синтез речи, перевод) для таких языков отсутствуют, что ускоряет их вытеснение и затрудняет изучение новым поколением.

## Цель
Разработать AI-платформу для поддержки и "оживления" одного из малых языков России (нанайский), создав базовые инструменты для его использования в цифровой среде.

## Метрики модели перевода
Оценка проводилась на отложенной тестовой выборке (hold-out set), не пересекающейся с обучающими данными.
BLEU-1 — 61%, BLEU-2 — 52%, BLEU-3 — 47% и BLEU-4 — 42%
Word Accuracy - 64%

## Ограничения
Границы применимости: 
1) Невозможно перевести слова и фразеологизмы, которых не было в датасете.
2) Чем длиннее предложение для перевода - тем хуже точность перевода.

## Bias/Fairness
Смещение домена (Domain Bias): Аутентичные данные (~5000 примеров), вероятно, неравномерно покрывают тематики (например, преобладают фольклор, но отсутствуют современные технические или бытовые темы).
Артефакты синтетических данных: Модель может несправедливо "предпочитать" те грамматические конструкции или слова, которые чаще генерировались инструментом синтеза, а не те, которые реально чаще используются носителями языка.
Культурная репрезентация: Модель не понимает культурного контекста. Перевод имен собственных, топонимов или культурно-специфичных понятий может быть неточным или унифицированным.

## Версия данных 
Модель facebook/mbart-large-50-many-to-many-mmt переводчика обучена на датасете aug_17_11.json из 15267 пар переводов - из них:
~5000 реальные данные
~10000 синтезированных.

## Требуемый результат
Веб-сайт, посвященный выбранному языку.

На сайте представлены интерактивные инструменты:
- "Говорящий словарь": пользователь вводит слово на русском или на малом языке, система показывает перевод и озвучивает его на малом языке (Text-to-Speech).
- "Переводчик": прототип нейросетевого переводчика для простых фраз с русского на малый язык и обратно.
- "Чтец сказок": нейросеть зачитывает вслух небольшие тексты (сказки, пословицы), помогая в изучении произношения.

## Структура проекта
**backend** - содержит серверный код, сервис с NMT-моделью и тесты  
**frontend** - web-приложение и интерфейс переводчика  
**model** - папка с кодом обучения модели, датасетами и вспомогательными методами. Не используется в работе сервиса. Нужна только для обучения.

## Запуск проекта

Запуск backend из каталога `backend/`:

1. Установить [Poetry](https://python-poetry.org/docs/#installation) 2.5
2. ```poetry install```
3. ```poetry run python model_downloader.py``` (если файлы модели еще не скачаны)
4. ```poetry run python main.py```  

Запуск frontend:

0. ```powershell -c "irm bun.sh/install.ps1|iex"``` (если не установлен bun)  
1. ```bun run i```  
2. ```bun run dev``` (для разработки)  
3. ```bun run build``` (для сборки)

Обучение модели из каталога `model/` (отдельное окружение, в контейнер сервиса не входит):

1. ```poetry install```
2. ```poetry run python -m finetuning.finetune```

Проверки перед коммитом (flake8 и black для backend, ESLint и `tsc` для frontend):

```bash
pip install pre-commit
pre-commit install
```

## Запуск в Docker

### Требования

- [Docker](https://docs.docker.com/get-docker/) 24+
- [Docker Compose](https://docs.docker.com/compose/install/) v2

### Сборка и запуск (из исходников)

Из корня репозитория:

```bash
# опционально: токен Hugging Face для моделей, скачиваемых не из Google Drive
cp .env.example .env

docker compose build
docker compose up -d
```

При первом запуске контейнер `models` скачает веса моделей из Google Drive (может занять несколько минут).

После готовности сервисов:

- фронтенд: http://localhost:3000
- API (Swagger): http://localhost:8000/docs

### Режим разработки в Docker

Hot-reload для backend и frontend:

```bash
docker compose -f docker-compose.yml -f docker-compose.dev.yml up
```

### Запуск из образов Docker Hub

Образы публикуются в Docker Hub:

- `artemdash/ai-sber-backend`
- `artemdash/ai-sber-frontend`
- `artemdash/ai-sber-models`

Запуск без локальной сборки:

```bash
export DOCKERHUB_USERNAME=artemdash
docker compose -f docker-compose.yml -f docker-compose.hub.yml up -d
```
